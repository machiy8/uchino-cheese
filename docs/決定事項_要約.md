# 決定事項の要約（実装に必要なものだけ）

元：ローカルの決定記録 `D:/claude/チーズ育成/memory/decision-log.md`（2026-10-08〜10-18）。要約 2026-10-19 チーズくん。**ここに書いたことは蒸し返さない。** 変える必要が出たら、PR ではなく質問として d に返す。

## 1. 事業と方針
- アプリ名：**うちのチーズ**（ストア表記案「うちのチーズ 〜放置で育てるチーズのペット図鑑〜」）。相棒は「うちの子」と呼ぶ世界観
- 対象：**大人の癒し系（13歳以上）**。子ども専用設計にしない（ファミリーポリシーの制約を避ける）
- 1本目の目的は**集客の型づくり**。収益は後
- 名称 NG：「チーズくん」（ピザハット）／「チーズ」単体（アンパンマンの犬）／「Qちゃん」（QBB）
- 工房主・案内役は差し替え可能（将来ウーパーちゃん案あり）。**本体の名前・パッケージ名・コードにウーパーを入れない**。初期は無人のナレーション「工房の手帳」
- 物販に広げる場合もグッズ（第28類・第16類）まで。実物のチーズ販売（第29類）はしない（雪印「おうちDEチーズ」と衝突し得る）

## 2. ゲームの骨格
- MVP＝なめこ型の放置図鑑育成＋**相棒チーズ1体**（なでる・話しかける・ごはん・お手入れ・寝かせる等）。友達機能は Phase2
- **ログインなし・端末内保存・ガチャなし**。相棒は**死なない・消えない**。なつき度・段階・日数・開いたヒントは減らない
- 図鑑は **82種**：実在65（季節限定3を含む）＋失敗種9＋工房オリジナル8。ID は `r01`〜`r65`・`f66`〜`f74`・`o75`〜`o82`。**公開後は既存の ID を変えない**
- 入力は7つ：乳4×菌5×圧搾4×熟成庫2×放置時間7×手入れ6×仕上げ13＝**87,360通り**。結果は必ず1つ・衝突0
- 判定順：実在種の完全一致 → 失敗種ルール（上から順） → 工房オリジナル（タイプ推定）。実在種は各1通りのレシピだけ
- 放置時間は7段階（30分〜14日）。現実の熟成期間を対数的に圧縮
- 仕上げは基本4値＋拡張9値（わら・木・酒・ワックス・布・シロン・ハート型・ピラミッド型・四角型）。**図鑑の登録数3ごとに1つ解放**
- 熟成棚は**3枠**。図鑑の名前は最初から表示（未登録はシルエット）
- 工房オリジナルは「実在の銘柄ではない」と明記する

## 3. ヒント（実在種へ導く仕組み）
- 分岐表は変えず、ヒントで導く。レシピカードの7つの穴を工程順（乳→菌→圧搾→熟成庫→手入れ→取り出し時間→仕上げ）に開く
- ひらめき（相棒のヒント）：1日 Lv1〜3＝2・Lv4〜6＝3・Lv7〜10＝4。持ち越しなし
- はじめてのレシピ帳（2〜8日目）・タイプのきほん・なかまのヒント・失敗種の初回ヒント・近さのしるし
- ヒント文は「ゲームのレシピ」として言う。**現実の製法を断定しない**（「〜みたい」）。現実の知識は図鑑登録後の一言解説で見せる
- 文の正本は `zukan_tools/out/hints.json`（`hint_gen.py` で生成。手で直さない）

## 4. 相棒
- 段階は「一緒に過ごした日数」で進む。日付の切り替えは端末のローカル時刻4時
- **なつき度で熟成を最大10%短縮**。仕込んだ時点の Lv で固定・分未満切り捨て（整数演算）。表は `zukan_tools/boost_table.py`
- 名前は変更可。初期名「うちの子」。1〜8文字（書記素）・絵文字不可・同梱フォントに無い字は不可・NG語検査あり
- NG語の印：行頭 `*`＝部分一致／`=`＝完全一致／なし＝長さで決める
- **チュートリアルの最初の熟成だけ1分**（入力は固定＝クリームチーズ r01）。2回目以降の30分ものは30分

## 5. 絵と顔
- 絵は**自作（Gemini で生成）・AI絵と公表**。外注しない。ストア説明文の AI 表記は公開前に決める
- **顔＝A方式**：体は AI の絵、顔はアプリの SVG 部品で重ねる。顔の型は8つ（maru・nemu・uru・tere・tsun・kira・futo・itome）×表情11。数値は `art_tools/face_style.json`、図形は `art_tools/face_parts.py`（**アプリも同じ値・同じ式**）
- 顔の線：色 `#582819`、太さ＝`13×1000÷顔の幅`（千分率）
- 「照れ」は 10/17 の新しい形で確定（困り眉なし・小さな笑み・濃いほっぺ）
- r56 フィオル・ディ・ラッテの顔の型は futo
- 最終段階（ヴィンテージ）の特別版は **r01 の4表情だけ**（描き込み方 c・`vintageArt: true`）。残り81種は SVG の顔で揃える（Phase1 では v1.1 で使う）
- アプリアイコンは**背景B（クリーム〜オレンジ）**。UIアイコン H25・H32 は作り直し済み
- くびの着せ替えの式の**正本は `art_tools/neck_calc.py`**（品の上端基準）。外れる13種は `faces.json` の `neckY`・`neckScale`。首のある体（`neck: true`）は r57・r58・r59・r61・r62
- 体の矩形：`faces.json` の `bbox`・`bodyMain`（ワイルド度 E2・E3 は bodyMain に合わせる）

## 6. 技術（実装計画 Phase1 で承認済み・10/18）
- Vite＋React 18＋TypeScript＋Capacitor。状態は Zustand、ゲームの中身は純粋関数。**Next.js は使わない**

- 通知：ローカル通知のみ（朝夜は1日2通まで・熟成完了・放置3日目/7日目）。**正確なアラーム権限は使わない**。Web版は予約通知なし。通知文に名前を入れない
