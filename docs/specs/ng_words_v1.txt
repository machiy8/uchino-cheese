# 仕様：work/相棒チーズ_仕様_v2.md §4（NG語）。照合の検査：work/ng_check.py
#
# ■ 選んだ基準
# 1. 対象は仕様 §4 の4分類だけ：①性的な語 ②差別語（障害・出自・民族・性的指向への蔑称、ヘイトの象徴）
#    ③暴力・自傷をあおる語 ④運営・公式を装う語（＋運営を装った詐欺でよく使う語）。
#    「ばか」「ぶす」「うんこ」のような軽い悪口・下品な語は入れない（端末内の名前で、外に出るのは本人が共有した画像だけ。
#    弾きすぎると普通の名前づけを邪魔する。13歳以上の大人の癒し系という対象にも合わせた）
# 2. 誤って弾かないことを優先する。照合は「3文字以上＝部分一致・2文字以下＝完全一致」なので、
#    3文字以上の語で、ありふれた名前・言葉を含んでしまう語は入れないか、別の形にした。
#    例：「ころす」→「ころすけ（コロ助）」を弾くので入れず「ころすぞ」「ころしてやる」にした／
#        「はくち」→「はくちょう」、「おなべ」→お鍋、「ちょん」→「ちょんまげ」、「けいこく」→「けいこくん」、
#        「えっち」→「えっちゃん」、「ばいぶ」→「ばいぶる」、英語の rape→grape・anal→canal・cum→cucumber・
#        cock→peacock・admin→badminton・spic→spicy・boob→booboo・ふぇら→ふぇらーり（フェラーリ）・jap→japan・ass→grass・paki→pakistan は入れない or 完全一致の印を付けた
# 3. 照合は正規化した形で行う（NFKC→カタカナをひらがなへ→英字を小文字→「ー・〜♪☆！？」を除く）。
#    この辞書は人が読める形で書き、アプリと ng_check.py が読み込み時に同じ正規化をかける。
#    正規化で同じ形になる語（例：サポート／さぽーと）は1つにまとめた
# 4. 出典：他社の辞書は写していない。一般に知られた語から自社で選んだ（仕様 §4「他社の辞書を写さない」）
#
# ■ 行頭の印（案・d確認待ち。仕様 §4 の規則に足す提案）
#   *語  … 長さに関係なく部分一致（漢字2文字の「運営」「公式」「死ね」などを「運営です」「死ねよ」でも弾くため）
#   =語  … 長さに関係なく完全一致（3文字以上だが部分一致にすると普通の言葉を弾く語）
#   印なし … 仕様どおり（正規化後3文字以上＝部分一致・2文字以下＝完全一致）
#   印を採らない場合は印を外すだけで仕様どおりに動く（そのとき「運営です」等は通る）
#
# ■ 書式：1行1語。# から行末まではコメント。空行は無視
